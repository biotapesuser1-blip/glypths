# Heroglyph Protocol Introduction

Heroglyph Protocol leverages validator graffiti to execute custom logic built by users within its ecosystem. This empowers validators and promotes decentralization throughout the chain.

## Modules of Heroglyph Protocol

### Identity
Serves as a wallet-linked identity system, similar to ENS (Ethereum Name Service). Validators must have a configured Identity for their produced blocks to execute.

### Ticker
Functions as an advanced Identifier for smart contracts, enabling unique functionality. Ticker ownership involves a Harberger tax system, allowing others to purchase it at the owner's designated price if funds are insufficient.

### When to Use Each Module
- **Identity**: Currently limited to Validators. Will extend to Delegators in the future.
- **Ticker**: Intended for advanced Validators and Developers. Developers must own a Ticker to link their protocols.
