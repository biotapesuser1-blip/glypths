# Overview of Obelisk

Obelisk operates through interconnected modules, emphasizing community-driven decisions.

## Key Modules in Obelisk
- **Registry:** Supports reserve creation, enables NFT collections, rewards contributors.
- **Reserve:** Permanently locks ETH for yield generation.
- **Megapools:** Pool system for staked NFTs; popular pools receive more ETH.
- **NFT Pass:** Acts as an identity linking wallet addresses to the protocol.
- **Tickers:** Pool identifiers managed contractually.

## Reserve Details
ETH contributions generate protocol-wide yields, managed and distributed among supported Megapools. Participation using NFTPass simplifies contributions.
